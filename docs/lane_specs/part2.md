Tests follow the repository's smoke-script convention (scripts/smoke_*.py printing a RESULT line; no pytest): where a spec names a tests/… path, the lane implements it as a smoke script with the same checks.

## Cross-lane rules (in addition to part 1's)

- **Invariance harness** (used by lanes 1–3, 6, 7): `tests/invariance/run_steps.py` runs `train_distill` (or the QAT runner) for N steps on a **synthetic 16-image TRAIN/VAL set** (random RGB + masks with 116 classes, 512×512), batch 2, `num_workers 0`, CPU, seed 42, determinism settings on, and writes one JSON per step: every telemetry field, `sha256(student.state_dict())`, `sha256(projection.state_dict())` if instantiated, `sha256(teacher_logits)` and `sha256(teacher_stage3)` for that step, and the NMF stream position. A **cross-commit run** = the harness executed from `git archive <old>` and `git archive <new>` exports in the pinned student image, outputs diffed. Pass = byte-identical JSON except fields the lane declares new. CPU is exact; the A40 repeat of the same harness (lane 5) is reported at tolerance because GPU bitwise reproducibility is what N10 measures, not something to assume.
- **Teacher stub**: for CPU harness runs the real SegNeXt-B is too slow only if the teacher image is unavailable locally; the harness accepts `--teacher stub` (a fixed-weight tiny network with the same output shapes and the same `nmf_stream` hook) for code-path tests, and `--teacher real` for the acceptance run. Cross-commit invariance must pass with the **real** teacher at least once (N = 4).
- **Selection scripts** (α, λ, clip norm, QAT epoch) share one contract: refuse partial inputs, read the band/rule from a committed JSON, write a JSON with a `rule_trace`, never read TEST, and the winner is always an existing run.
