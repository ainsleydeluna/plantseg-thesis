## Cross-lane rules (apply to all eight)

- **Frozen**: `src/eval/metrics.py` blob `cbd5fa86…` (recorded as `metric_impl_sha256 9898d6dc…`). Add `tests/test_frozen_blobs.py` asserting `git hash-object src/eval/metrics.py == cbd5fa86…`; every lane's test run includes it. No lane computes a metric by editing metrics.py — variants are computed from `sufficient_stats.npz` in new modules.
- **Frozen**: `bootstrap.py:113-131` task matrix and the TEST driver in `ingest.py:202-203`. New entry points only.
- **Governed** (pod pins change; merge post-B66 only): `src`, `configs`, `scripts`, `requirements*`, `Dockerfile`, `docs/EVALUATION_CONTRACT.md`, `docs/IMPLEMENTATION_CONTRACT.md`. Each merge that touches them is recorded as a new pin; every later pod re-runs its preflight at that pin.
- **Artifact compatibility**: pre-lane artifacts (R3 teacher, DL-17 run1/run2, s43/s44 re-scores) are never re-scored to satisfy a schema; readers derive missing fields (L-AM5 rule) and tolerate extra ones. Byte-identity of `per_image.jsonl` holds within a commit only; CMP full mode stays pinned to seed 42.
- **Status**: everything produced before adviser approval is `artifact_status: provisional`; rehearsal outputs are `rehearsal`; only TEST day writes `official`.
- **STOP for every lane**: any diff in `metrics.py`; any change in an existing per-image or dataset-level value on a regression re-score (see L-AM5 d4); any read of TEST outside the M11 isolation path; any edit inside the frozen task matrix.

## 2. L-AM13 — upstream-protocol scoring

**(a)** AM-13, AM-16 item 4, AM-17 item 1(e). Implements the upstream PlantSeg test protocol as in `tqwei05/PlantSeg` (SOURCE-PROVEN from the configs): `Resize(scale=(2048, 512), keep_ratio=True)` with mmcv semantics (scale factor = min(2048/long, 512/short); bilinear for the image; the mask is never resized); pad the *normalized* tensor to a multiple of 32 with 0.0 (`size_divisor=32`); whole-image inference at batch 1; logits upsampled bilinear (`align_corners=False`) to the padded input shape, cropped to the rescaled shape, upsampled bilinear to the original shape, then argmax; confusion accumulated against the original-resolution mask (ignore 255; 116 classes, background 0); dataset-level mIoU via the frozen `miou_from_confusion` (union-present) — the same function, on a different confusion. Both bilinear steps are kept to match MMSeg's `predict_by_feat` → `postprocess_result`. Normalization and channel order are exactly those of each model's existing evaluator path (student: `core_preprocess` numerics; teacher: the R3 adapter path) — only the geometry changes. Protocol id `upstream/1.0.0`; the canvas protocol keeps `core_preprocess/1.0.0`. Note in the artifact and Ch4 that the upstream MSCAN-B class count for 42.05% is NOT DETERMINABLE (the L config used 116, T used 115).
**(b)** New `src/eval/protocols.py` (rescale, pad, two-step logit resize, original-resolution accumulation), `src/data/` variant returning the original-resolution mask and image (new file, no change to `PlantSegDataset`), `src/eval/adapters.py` (protocol switch for both models), `scripts/evaluate_model.py` (`--protocol {canvas,upstream}`); `docs/EVALUATION_CONTRACT.md` (new protocol section). All governed. metrics.py untouched.
**(c)** In: checkpoint, split, protocol. Out: the standard 4-file artifact with `summary.protocol = {name, version, resize:{short:512,long_max:2048,interp:"bilinear"}, size_divisor:32, pad_value_normalized:0.0, logit_upsample:["bilinear_to_padded","crop","bilinear_to_original"], align_corners:false, scored_resolution:"original"}`; per-image rows gain `ori_shape`, `rescaled_shape`, `padded_shape`. `metric_impl_sha256` unchanged.
**(d)** d1 unit: rescale on (h,w) ∈ {(1009,1200),(256,256),(512,2048),(300,1500)} gives (512,609),(512,512),(512,2048),(410,2048)… computed as `round(s·h), round(s·w)` with s = min(2048/max, 512/min) — assert against mmcv's `rescale_size` if importable, else the formula. d2 unit: a synthetic 2-class logit map where logit-then-argmax and argmax-then-nearest disagree at a boundary pixel → the implementation returns the logit-upsampled answer. d3 unit (geometry-only proof): a random 512×512 input through both protocols yields bitwise-equal pre-crop logits for the student and for the teacher (no rescale, no pad in either path). d4 shape smoke: student forward at (1,3,512,672), (1,3,512,2048), (1,3,416,512) on CPU returns logits with stride-8 shapes; if the head has a fixed pooling kernel that fails → STOP and report (a model change is out of scope). d5 real (VAL, local CPU): E1 s42 and the teacher of record scored under `upstream`: 846 rows; every `pred_shape == ori_shape`; two runs bitwise identical on `per_image.jsonl`; the union-present eligible count reported; deltas vs the canvas values (E1 0.36308 CPU; teacher 0.38577) recorded — no pass threshold on the values. d6: `--split test` refused without the TEST-day manifest flag (M11).
**(e)** No dependency. Needed before the first KD run (E1 on VAL, AM-16 item 4) and for item 1(e). Teacher run needs the teacher image locally (feasibility smoke: CPU inference in Docker; expected ≈ 1.3× R3's runtime, read from `r3_console.log`).
**(f)** Risk: two-step vs one-step upsampling changes boundary pixels — that is why it is pinned. STOP: d3 or d4 fails.

## 6. L-AM17-MDE — shifted-null simulation + analytic cross-check

**(a)** AM-17 items 3 and 3(f). Inputs: per-image VAL `disease_only_miou` for E1 s42 (DL-17 run1), s43, s44 (in-chain A40 re-scores), AM-5 exclusion applied (L-AM5 derivation), asserted identical excluded sets and identical image order. Differences 43−42, 44−42, 44−43. n_planning = round(1561 × included/846). For each pair and each δ on a grid 0.000…0.050 step 0.001: B=2,000 resamples of size n with replacement from (d + δ), RNG `default_rng(42)`, tested with `scipy.stats.wilcoxon(x, zero_method='pratt', alternative='greater', correction=True, method='approx')`; power = share of p < 0.00625; MDE_W(pair) = smallest δ with power ≥ 0.80 at δ and at the next two grid points (MC noise guard; MC SE ≈ 0.009 at 0.8); MDE_W = max over pairs. Analytic: SD_Δ = max over pairs of SD (ddof=1); dz = (2.4977+0.8416)/√n; MDE_t = dz·SD_Δ; range MDE_t × [1.023, 1.076]. τ_P = 0.010; `power_caveat = MDE_W > τ_P`.
**(b)** New `src/stats/mde.py`, `scripts/mde_entry.py`. Non-governed except `src`.
**(c)** Out: `reports/derived/mde_entry_<UTC>.json` = {artifacts:{seed:{run_id, sha256s}}, n_included, K_excluded, n_planning, pairs:{"43-42":{n, mean, sd, share_ties, power_curve:[[δ,power]…], mde_w}, …}, mde_w, sd_delta, dz_mde, mde_t, mde_t_range, tau_p, power_caveat, scipy_version, seed, git_commit} plus a one-line decision-log string.
**(d)** d1 unit: synthetic d with n=846: 30% exact zeros, rest N(0, 0.12) → analytic MDE_t within 1e-9 of 0.0845·SD (n=1,561 case); power at δ=0 ∈ [0.001, 0.015]; power monotone non-decreasing along the grid after the 3-point guard; power at MDE_W ≥ 0.80. d2 unit: no zeros, N(0, 0.10) → MDE_W/MDE_t ∈ [0.95, 1.15] (ARE 0.955). d3: same seed → identical bytes; different seed → MDE_W within one grid step. d4 real (post-B66): excluded sets identical across the three seeds; image ids aligned; no NaN; entry written once and its sha256 recorded in the decision log with the DL-27 band.
**(e)** After L-AM5 (derivation), B66 retrieval, DL-17 PASS. Gates the first KD run (AM-17 item 3 "before the first KD run").
**(f)** Risk: the constant-shift null removes Pratt zeros — the pre-registered approximation; labelled planning proxy. STOP: excluded sets differ across seeds (manifest mismatch) or DL-17 not PASS.
